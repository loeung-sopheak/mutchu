## About the Project

**Mutchu** is a Flutter-based application designed to simulate a real-world food and drink delivery platform. It is being developed as a study project to gain hands-on experience with:

- Building a feature-rich mobile application for iOS and Android.
- Implementing a clean and maintainable project architecture.
- Integrating with a Supabase backend for authentication and data storage.
- Managing application state effectively.
- Writing and running automated tests.

This project currently includes the foundational setup for a multi-platform Flutter application with a connected backend service.

## Features

The application is planned to include the following core features:

- **User Authentication**: Sign up, log in, and profile management using Supabase.
- **Browse Items**: View a list of available food and drink items.
- **Order Management**: Add items to a cart, place orders, and view order history.
- **Real-time Updates**: Get live status updates on orders.
- **Cross-Platform**: Run on mobile, web, and desktop (Windows, Linux, macOS).
